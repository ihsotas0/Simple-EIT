# Collection Procedure

1. Add a standard volume (150 mL) of tap water to the water container in the
   test rig. Use the same tap water if it needs to be replaced.

3. Run data_collector.py for instrument (select: I).

3. Draw 16 equal sections in the test rig. 4 quadrants each split into two pie
   slices, with all the slices being cut in half by a second circle with a
   radius smaller than the test rig as to make each new section have equal area.

5. Run data_collector.py for instrument (select: Q). Record 10 measurements of
   the object for each of the 16 sections in the test rig. Rotate them each
   time so they do a full rotation for each section.

5. Repeat step 5 for a finger, small cap filled with air and a mass to hold it
   down, and an eraser.
